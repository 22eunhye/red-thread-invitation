# 붉은 실 — 연말 파티 모바일 초대장

모바일 청첩장처럼 링크 하나로 보내는 연말 파티 초대장입니다.
빨간 실로 묶인 봉투를 누르면 실이 풀리고 편지가 나오면서 초대장이 펼쳐집니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 초대장 페이지 (이 파일 하나로 동작) |
| `Code.gs` | 닉네임 등록을 받는 Google Apps Script |

## 1. 내용 바꾸기

`index.html` 아래쪽 `CONFIG`만 고치면 날짜, 장소, 참가비, 계좌 등이 전체에 반영됩니다.

```js
const CONFIG = {
  date: "2026-12-20",
  startTime: "18:00",
  endTime: "21:00",
  placeName: "장소 이름",
  placeAddress: "서울시 ○○구 ○○로 00",
  fee: 50000,
  giftCap: 15000,
  bank: "○○은행 000-0000-0000",
  accountHolder: "예금주 ○○○",
  scriptUrl: "",            // 2단계에서 받은 웹 앱 주소
  nicknameDue: "12월 ○일까지 등록해 주세요",
  showNicknames: true,      // 등록된 닉네임 목록 공개 여부
};
```

`scriptUrl`이 비어 있으면 닉네임 등록은 예시(저장 안 됨)로 동작합니다.

## 2. 닉네임 등록 연결 (Google 스프레드시트)

1. 구글 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포합니다.
4. 나온 URL을 `CONFIG.scriptUrl`에 넣습니다.

- 등록 내용(시각·이름·닉네임)은 스프레드시트에 쌓이고, 초대장에는 **닉네임만** 보입니다.
- 이미 쓰인 닉네임은 등록되지 않고, 같은 이름으로 다시 내면 닉네임이 바뀝니다.
- `Code.gs`의 `NOTIFY_EMAIL`에 주소를 넣으면 등록될 때마다 메일이 옵니다.

## 3. GitHub Pages로 배포

1. 새 저장소에 `index.html`을 올립니다.
2. **Settings → Pages**에서 Branch를 `main`으로 선택합니다.
3. `https://아이디.github.io/저장소이름/` 주소를 친구들에게 보내면 끝.

카카오톡 미리보기 이미지는 `og:image` 주소를 저장소에 올린 이미지 주소로 바꿔주세요.
